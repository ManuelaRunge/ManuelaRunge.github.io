# Git authorship

For future commits created by an AI agent in this repository, use
`Codex <codex@openai.com>` as the commit author (for example, with
`git commit --author="Codex <codex@openai.com>"`). Apply this per commit;
do not change the user's Git identity for their own commits.

Do not rewrite existing commit authors unless the user identifies the commits
to change and authorizes rewriting their history.
